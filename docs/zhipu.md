# 接入智谱大模型（GLM）

智谱开放平台（BigModel）提供与 OpenAI 兼容的接口，FishAi 可以直接接入。其中 **GLM-4.7-Flash 完全免费**，适合日常翻译；需要更好的效果可以换成付费的 GLM-5.3-Flash，费用也很低。

> 本文写于 2026 年 10 月。模型名称和价格会变化，请以 [智谱官方文档](https://docs.bigmodel.cn/cn/guide/start/quick-start) 和 [价格页](https://bigmodel.cn/pricing) 为准。

---

## 第一步：注册账号

1. 打开 [智谱开放平台](https://bigmodel.cn)，点击右上角「注册/登录」；
2. 按页面提示完成注册并登录。

## 第二步：创建 API Key

1. 登录后进入「个人中心 → [API Keys](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)」；
2. 新建一个 API Key，起个名字（比如 `FishAi`）；
3. 复制生成的 API Key。

> **注意**：智谱的「模型标准 API」和「GLM Coding Plan（编程套餐）」的 API Key 是分开管理的，互不通用。FishAi 请使用上面「API Keys」页面创建的**标准 API Key**。如果你用的是编程套餐的 Key，Base URL 要改成 `https://open.bigmodel.cn/api/coding/paas/v4`，额度也按套餐计算。

API Key 相当于你账户的密码，不要发给别人，也不要贴到公开的地方。泄露后在同一页面删除它，再新建一个即可。

## 第三步：在 FishAi 中添加模型

1. 点击菜单栏的小鱼，打开「设置」，切到「模型」；
2. 点左下角的 `+` 新建一个模型，填写：

| 字段 | 填写 |
| --- | --- |
| 名称 | `智谱`（随意，会显示在翻译面板的模型下拉框里） |
| Base URL | `https://open.bigmodel.cn/api/paas/v4` |
| API Key | 第二步复制的 Key |
| 模型 | `glm-4.7-flash`（免费），或 `glm-5.3-flash` |

3. 点「测试连接」，看到绿色的 ✓ 和一句翻译结果，就说明接入成功。

API Key 保存在 macOS 钥匙串里，第一次读取时系统可能弹窗询问，选「始终允许」。

## 第四步：开始使用

在翻译面板右侧的模型下拉框里选「智谱」，再在旁边选一个提示词（翻译、解释、润色、总结……），就会用智谱模型输出结果。切换后立即重新翻译。

---

## 选哪个模型

| 模型 | 费用 | 适合 |
| --- | --- | --- |
| `glm-4.7-flash` | 免费 | 日常翻译，零成本 |
| `glm-5.3-flash` | 输入 0.8 元、输出 2.8 元 / 百万 tokens | 长文、专业内容、解释和润色，效果更好 |

翻译一段几百字的文字通常只用几百到一两千 tokens，用 `glm-5.3-flash` 每次也不到一分钱。账户余额和用量可以在智谱平台的「财务中心」查看。

模型名请全部用**小写**，和官方文档里的写法一致。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 测试连接提示 401 / 鉴权失败 | API Key 填错或已删除；重新复制，注意不要带空格 |
| 提示余额不足 | 付费模型需要先在智谱平台充值；或者换成免费的 `glm-4.7-flash` |
| 提示模型不存在 | 检查模型名的拼写和大小写；确认该模型仍在官方模型列表中 |
| 用的是编程套餐，提示无权限 | 编程套餐的 Key 要配 `https://open.bigmodel.cn/api/coding/paas/v4`，见第二步的注意事项 |
| 出字慢 | 优先选 Flash 系列；也可以在翻译面板先用「系统翻译」，需要解释、润色时再切到智谱 |

更多接入方式请参考 [用户手册](../README.md#2-内置接口和接入外部接口)。
